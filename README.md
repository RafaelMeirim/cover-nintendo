# Projeto para cover em PT-BR de jogos do Nintendo Switch 1 e 2

# Como usar
Arquivos em PDF estão formatados como folha de ofício, mas na impressão utilizem o papel em folha tamanho A4 com orientação automática e tamanho real.

# Arquivos do Photoshop
Na pasta da capa contém o arquivo zipado em 7z contendo o  PSD para realizar ajustes com o Photoshop. Para descompactar use o 7zip

# Papel recomendado
Papel dupla face Glossy 120g A4 

# Impressora recomendada
Preferencialmente em jato de tinta qualidade alta, mas pode ser impresso em impressora laser também.
